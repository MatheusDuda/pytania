# Pytania
 
Um banco de questões para auxiliar em estudos pessoais.
 
O objetivo do projeto é permitir cadastrar questões da minha área de estudo, respondê-las
uma a uma e, ao final, ver quais acertei e quais errei — servindo como ferramenta de
revisão e acompanhamento do meu aprendizado.
 
## Objetivos
 
- Cadastrar questões de múltipla escolha por área/assunto
- Responder as questões e receber a correção ao final
- (Futuro) Manter um histórico de tentativas para acompanhar minha evolução
## Stack
 
- **Backend:** Python + FastAPI
- **Banco de dados:** SQLite (inicialmente), com possível migração para PostgreSQL
- **Frontend:** React + Vite + TypeScript
